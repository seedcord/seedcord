This page is the catalog. Each section names one thing the pipeline supports and shows it rendering. The code samples are real seedcord code because twoslash compiles them against the published packages.

## Fences

The header on a plain fence holds the copy button.

```ts title="src/commands/Ping.ts"
import { SlashHandler, SlashRoute } from '@seedcord/gateway';

@SlashRoute('ping')
export class Ping extends SlashHandler<'ping'> {
    public async execute(): Promise<void> {
        await this.reply('Pong');
    }
}
```

A fence with no `title` still gets the header.

```sh
pnpm add @seedcord/gateway
```

Tagging a fence `output` drops the copy button, for lines a terminal printed back.

```sh output
✓ 12 routes written to .seedcord/manifest.ts
✓ 3 commands deployed to the test guild
```

## Twoslash

Tagging a fence `twoslash` runs the TypeScript compiler over it while the page builds. An error the sample never declared fails the build. A sample that stopped compiling cannot reach a page.

Errors, `^?` queries, and completions all render on a `twoslash` fence. A checked fence weighs about what a plain one does. Adding `hovers` next to the tag makes every token hoverable, which prints that token's whole type into the page and costs around five times the bytes. Use it on the samples where the types are the lesson.

A declared error renders under the line it came from, with the caret under the squiggled token.

```ts twoslash title="src/commands/Ping.ts"
// @errors: 2345
import { SlashHandler, SlashRoute } from '@seedcord/gateway';

@SlashRoute('ping')
export class Ping extends SlashHandler<'ping'> {
    public async execute(): Promise<void> {
        const detailed = this.options.getBoolean('detaild');
    }
}
```

An error on the first token of a line.

```ts twoslash
// @errors: 2304
timoutMs = 3000;
```

A short message under a token far along the line. The card widens to reach it.

```ts twoslash
// @errors: 2304
const config = { intents: [1, 2], partials: [], token: nope };
```

A `^?` marker prints the inferred type under the line.

```ts twoslash
const routes = ['ping', 'ban'] as const;
const first = routes[0];
//    ^?
```

A run of `^` marks the characters above it.

```ts twoslash
const token = process.env.DISCORD_BOT_TOKEN;
//    ^^^^^
const ready = true;
```

A `^|` marker draws what an editor would offer at that point. The code is incomplete by definition. `@noErrors` covers that.

```ts twoslash
// @noErrors
const routes = { ping: 1, pong: 2, purge: 3, prune: 4 };
routes.p;
//      ^|
```

## Hovers

On a `twoslash hovers` fence every token carries the type the compiler gave it. Hover one, or tab into the block and walk it with the arrow keys.

```ts twoslash hovers
import { SlashHandler, SlashRoute } from '@seedcord/gateway';

@SlashRoute('ping')
export class Ping extends SlashHandler<'ping'> {
    public async execute(): Promise<void> {
        const detailed = this.options.getBoolean('detailed');
        await this.reply(detailed === true ? 'Pong, at length' : 'Pong');
    }
}
```

## Cuts

The compiler reads the whole fence. Cut markers set the first and last line that renders. A sample can carry the imports and the class it needs to compile without showing either.

`// ---cut---` drops everything above it.

```ts twoslash
import { SlashHandler, SlashRoute } from '@seedcord/gateway';
// ---cut---
@SlashRoute('ping')
export class Ping extends SlashHandler<'ping'> {
    public async execute(): Promise<void> {
        await this.reply('Pong');
    }
}
```

A pair of `// ---cut---` and `// ---cut-after---` keeps the middle. Lines taken out of a class body render flush left, and the copy button gives you those same lines.

```ts twoslash
import { SlashHandler, SlashRoute } from '@seedcord/gateway';

@SlashRoute('ping')
class Ping extends SlashHandler<'ping'> {
    public async execute(): Promise<void> {
        // ---cut---
        const detailed = this.options.getBoolean('detailed');
        await this.reply(detailed === true ? 'Pong, at length' : 'Pong');
        // ---cut-after---
    }
}
```

`// ---cut-start---` and `// ---cut-end---` drop a range out of the middle and keep both ends.

```ts twoslash
const routes = ['ping', 'ban'] as const;
// ---cut-start---
const unrelated = routes.length;
// ---cut-end---
const first = routes[0];
//    ^?
```

## Reference links

A symbol link is a markdown link with a `ref:` target, and the slug comes off the symbol. [Notice](ref:core/Notice), [Silence](ref:core/Silence), and [Fault](ref:core/Fault).

A multi-word name kebab-cases itself: [SlashHandler](ref:gateway/SlashHandler) reaches `slash-handler`. A dotted member anchors on its owner's page: [Paginator.start](ref:core/Paginator.start) reaches `paginator#start`. A generic drops off the end, which puts [`Plugin<Options>`](ref:core/Plugin<Options>) and [Plugin](ref:core/Plugin) on one page.

The link text is free. [The card a refusal renders](ref:core/Notice) points at the same page as its own name. Each package is its own segment, so [createSeedcord](ref:http/createSeedcord) and [Seedcord](ref:gateway/Seedcord) each reach their own. Every one of these opens in a new tab.

A heading takes no symbol link, since its text also renders in the table of contents. The build says so by name.

## Inline marks
