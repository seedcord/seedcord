`@seedcord/kit` holds the everyday Seedcord building blocks: the Discord component builder bases (`BuilderComponent`, `RowComponent`), the `Notice` error base, and the typed customId codec (`CustomId`). Install it on its own to build and decode components without pulling in the full framework. Core re-exports its public surface, so `from 'seedcord'` keeps working unchanged.
